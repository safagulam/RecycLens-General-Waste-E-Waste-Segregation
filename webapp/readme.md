

## Overview

This web app allows users to report waste by uploading images. The system classifies the waste using a model and helps NGOs take action for proper disposal.


## Roles

### 👤 User

* Upload image of waste
* Get automatic waste classification
* Add location/details
* Submit report

---

### 🏢 NGO

* View reported waste
* Check classification results
* Track locations
* Take action for cleanup

---

## Features

* Image upload
* AI-based waste classification
* Real-time reporting
* Role-based access (User / NGO)

---

## How It Works

1. User uploads waste image
2. System classifies the waste
3. Report is stored with details
4. NGO views and responds to report

---

## Technologies Used

* Python
* OpenCV / YOLO
* Web (HTML, CSS, JavaScript)
* Database (for storing reports)

---

## Usage

* User: Upload and report waste
* NGO: Monitor and manage reports

---



To make waste management faster and more efficient using technology.
